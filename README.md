# DAA Assignment 2 - Data Structures

## Description

This project was created for Assignment 2 of the Design and Analysis of Algorithms course.

The goal of the assignment is to implement basic data structures from scratch, measure their performance, and compare their behavior using different workloads.

The project contains three data structures:

- DynamicArray
- MyLinkedList
- MinHeap

The project also includes:

- operation metrics
- JUnit 5 tests
- benchmark workloads
- CSV results
- performance plots
- complexity analysis
- loop invariant proofs

- Java 17 or newer
- Apache Maven
